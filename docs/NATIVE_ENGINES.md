# Integrated native engines — Mission 002

Windows contains Python 3.13, PySide6/Qt 6.12, yt-dlp, Playwright, Selenium, Chromium 159.0.8154.6, matching ChromeDriver, FFmpeg and FFprobe. FFmpeg is the FFmpeg-Builds x64 LGPL shared build `n9.0.2-58-g8c7ef49002-20261119`, with matching avcodec, avdevice, avfilter, avformat, avutil, swresample and swscale DLLs. SHA-256 and exact source URLs are pinned in tools/native-windows.lock.json. FFmpeg's [official download page](https://ffmpeg.org/download.html) identifies FFmpeg-Builds as a Windows binary provider; the version/architecture/capabilities are independently tested after download.

The application resolves its installation directory from the frozen executable, then uses `engines/ffmpeg`. Both executables must run successfully and expose H.264/AAC/MP4 support before READY. A configured external override is explicit, optional, and must include a working matching ffprobe. A present-but-broken runtime fails clearly. The frozen app never searches PATH for an alternative FFmpeg. The wheel can explicitly provision the pinned runtime into its application data directory.

Browser discovery uses bundled Chromium. The matching driver is downloaded from Google's official Chrome for Testing distribution and its local checksum/version recorded; no separate upstream checksum was supplied. The unused Selenium Manager executable was removed from the package. Its x86 architecture was identified during dependency inspection; direct bundled driver selection removes the need for it.

`evidence/windows-native-dependencies.json` inventories every PE file and its imports, architecture, size and hash. Windows system API sets are recognized without copying OS DLLs. Runtime tests additionally execute the package with a system-only PATH while the development venv is physically unavailable. No GPU codec or driver is needed for the tested software decode/merge path. H.264/AAC decoding, stream-copy MP4 merge, HLS processing and yt-dlp separate-format merging have controlled fixtures. Hardware acceleration and arbitrary codec conversions are not acceptance claims.

The installer contains the same tested portable tree, creates a Start Menu entry and provides conventional uninstallation. State and media live outside the installation directory; installer testing checks their preservation across reinstall and uninstall. No source tree, local virtual environment or external FFmpeg location is required after installation.

Android bundles platform-specific Python/yt-dlp/QuickJS and FFmpeg/FFprobe native components from youtubedl-android 0.18.1. Each app process validates the local runtime using bundled synthetic video/audio streams, MediaExtractor track/duration checks, and full FFmpeg decoding before enabling split-stream selection. This test runs on the device and does not contact a service. The release's instrumented and interactive tests use an x86_64 emulator. ARM64 dependency inspection cannot substitute for physical ARM64 execution.

The upstream Android FFmpeg archive included unused capture/plugin libraries with unresolved dependencies. tools/prepare_android_native.py follows the actual executable dependency closure, resolves upstream archive symlinks, and packages only required libraries for each supported ABI. The original upstream archive is preserved in the build cache; pruning is reproducible and does not touch user data. The ELF report records architecture, imported libraries and segment alignment. The current app is not certified for every Android device/page-size configuration; consult the recorded alignment and device scope before making compatibility claims.

Native runtime updates must repeat the pinned-download, import inspection, controlled media, installed-package, real-source and preservation checks before publishing. An executable merely existing on disk is never a passing capability check.

The Widgets-only bundle excludes unused Qt PDF and virtual-keyboard plugins and their QML/Quick dependency families. Qt networking uses the packaged Schannel backend. The final reduced package is audited and exercised again after pruning.
